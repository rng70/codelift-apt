codelift APT repository

Extract fully qualified function names from npm, PyPI, NuGet, Maven, Cargo, Go and RubyGems packages.

Install

curl -fsSL https://rng70.github.io/codelift-apt/install.sh | sudo sh
sudo apt install codelift

Packages

PackageContents
codeliftmetapackage — pulls in the CLI build
codelift-clifully static build, no dependencies (servers, containers)
codelift-guibuild with the graphical symbol browser + desktop entry

codelift-cli and codelift-gui both provide /usr/bin/codelift and are mutually exclusive — installing one replaces the other.

Architectures: amd64, arm64, armhf.
